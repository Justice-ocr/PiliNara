  Windows slider callbacks, live playback recovery and `await play()` on init.
  `_updatePlaybackState` only runs for the active global instance, so
  background tabs/split panes never drive the system media session; it falls
  back to the cached position when the native player is gone. The removed
  `onStatusChange`/`onPositionChange` calls are not reintroduced.
